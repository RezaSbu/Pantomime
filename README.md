# ادابازی (Adabazi) — اپلیکیشن حرفه‌ای پانتومیم و بازی گروهی فارسی

**ادابازی** یک وب‌اپلیکیشن پیش‌رونده (PWA) کاملاً آفلاین، فارسی و راست‌به‌چپ (RTL) برای برگزاری مسابقات گروهی پانتومیم در جمع‌های دوستانه و خانوادگی است.

---

## ویژگی‌های کلیدی

- **بانک کلمات جامع و واقعی (۲٬۴۸۵ واژه و عبارت بدون تکرار):**
  - ۱۸ دسته‌بندی اصلی: فوتبال، ورزش، فیلم، سریال، کارتون، سلبریتی، مشاهیر، کتاب، موسیقی، اماکن، شهر و کشور، ضرب‌المثل، مفاهیم انتزاعی، حیوانات، غذا، شغل، اشیاء، تکنولوژی و علم.
  - هر دسته شامل دقیقاً **۱۳۵ واژه** سطح‌بندی‌شده (۵ آسان، ۳۰ متوسط، ۱۰۰ سخت).
  - **۵۵ عبارت چندمرحله‌ای اختصاصی** برای چالش ویژه **موضوع طلایی ۳۰ امتیازی**.
  - رعایت دقیق نسبت محتوایی در دسته **فوتبال** (۷۰٫۴٪ بازیکنان / ۲۹٫۶٪ سایر موضوعات فوتبالی؛ و در میان بازیکنان ۷۰٫۵٪ خارجی از ملیت‌های متنوع و ۲۹٫۵٪ ایرانی).
  - رعایت دقیق نسبت محتوایی در دسته **سلبریتی** (۸۵٫۲٪ چهره‌های مشهور ایرانی و ۱۴٫۸٪ خارجی با حفظ نسبت در تمام سطوح دشواری).
- **موتور امتیازدهی و پاداش سرعت دقیق:**
  - کلمات عادی: آسان ۲ امتیاز (پاداش +۲ تا ۱۵ ثانیه)، متوسط ۴ امتیاز (پاداش +۳ تا ۳۰ ثانیه)، سخت ۶ امتیاز (پاداش +۴ تا ۴۵ ثانیه).
  - ضرب‌المثل‌ها: آسان ۵ امتیاز (پاداش +۲ تا ۲۰ ثانیه)، متوسط ۸ امتیاز (پاداش +۳ تا ۴۰ ثانیه)، سخت ۱۰ امتیاز (پاداش +۵ تا ۶۰ ثانیه).
  - موضوع طلایی: ۳۰ امتیاز پایه، زمان ۲۴۰ ثانیه، پاداش سرعت +۱۰ تا ۶۰ ثانیه و +۵ تا ۱۲۰ ثانیه.
- **الگوریتم انتخاب هوشمند وزندار:**
  - رعایت نسبت ۶۰٪ سخت، ۳۰٪ متوسط و ۱۰٪ آسان مستقل از تعداد کلمات ذخیره شده در هر سطح.
  - توزیع متعادل دسته‌ها، جلوگیری از تکرار کلمات در یک مسابقه و اطلاع‌رسانی شفاف در صورت اتمام کلمات یک سطح.
- **مکانیزم منصفانه اجرای بازی:**
  - نمایش محرمانه کلمه فقط برای اجراکننده پیش از شروع تایمر و امکان مخفی‌سازی مجدد در حین اجرا.
  - تایمر دقیق مبتنی بر ساعت واقعی سیستم (`Date.now()`) مقاوم در برابر خاموش شدن صفحه، تغییر تب یا رندر مجدد.
  - تعویض کلمه (حداکثر ۱ بار برای هر کارت با کسر ۱ امتیاز و ریست تایمر) و گزارش کلمه نامعتبر (بدون جریمه و با حفظ دقیق زمان باقی‌مانده).
  - گردش چرخشی منصفانه تیم شروع‌کننده در هر دور و برگزاری **چالش مرگ ناگهانی** با فرصت برابر در صورت تساوی صدرنشین‌ها.
- **مدیریت بانک کلمات، پشتیبان‌گیری و PWA آفلاین:**
  - افزودن، ویرایش، حذف، تغییر دسته و سطح، صف بررسی کلمات گزارش‌شده، گزارش زنده کنترل کیفیت و ورود/خروجی `JSON` و `CSV`.
  - ذخیره‌سازی خودکار در `IndexedDB` و `LocalStorage` و قابلیت نصب روی موبایل (Android / iOS) و دسکتاپ.

## معماری نرم‌افزار

کدهای پروژه کاملاً ماژولار و مستقل از رابط کاربری طراحی شده‌اند:

- `src/engine/scoringEngine.ts`: محاسبه امتیاز پایه، پاداش سرعت، جریمه تعویض، جدول رده‌بندی و تشخیص تساوی.
- `src/engine/timerEngine.ts`: موتور زمان‌سنجی دقیق بر پایه زمان سیستم با پشتیبانی از حالت خودکار، دستی و نامحدود.
- `src/engine/roundManager.ts`: مدیریت ۲ تا ۸ تیم، ترتیب چرخشی دورها و دورهای مرگ ناگهانی.
- `src/engine/wordSelector.ts`: الگوریتم انتخاب تصادفی وزندار کلمات، حفظ تعادل دسته‌ها و نسبت‌های ایرانی/خارجی.
- `src/engine/gameEngine.ts`: ماشین وضعیت کامل مسابقه، محافظت در برابر دوبار کلیک و ثبت رویدادهای قابل ردیابی (`ScoreEvent`).
- `src/engine/soundEngine.ts`: سنتز افکت‌های صوتی آفلاین با Web Audio API و بازخورد لرزشی (`navigator.vibrate`).
- `src/storage/db.ts` و `src/storage/settingsStorage.ts`: لایه ذخیره‌سازی آفلاین در `IndexedDB` و `LocalStorage`.
- `src/data/`: بانک کلمات تفکیک‌شده ۱۸ دسته + موضوع طلایی و موتور اعتبارسنجی کیفیت (`validateWordBank`).

## نصب و راه‌اندازی

### ۱. نصب وابستگی‌ها

```bash
npm install
```

### ۲. اجرای محیط توسعه

```bash
npm run dev
```

برنامه روی پورت `3000` اجرا می‌شود.

### ۳. اجرای تست‌های واحد (Vitest)

```bash
npm test
```

### ۴. اجرای اسکریپت اعتبارسنجی بانک کلمات

```bash
npm run validate:words
```

### ۵. ساخت نسخه نهایی (Production Build + PWA Service Worker)

```bash
npm run build
```
